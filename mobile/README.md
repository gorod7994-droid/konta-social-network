# KONTA для iPhone (Expo SDK 58)

Нативні екрани KONTA з єдиною базою Supabase, спільною із сайтом konta.pp.ua.

## Встановлення на Windows і тестування через Expo Go

1. На GitHub натисни **Code → Download ZIP**, розпакуй **нову** версію репозиторію (не використовуй старий ZIP).
2. Відкрий папку `mobile`, у рядку адреси Провідника введи `cmd`.
3. Введи команди по черзі:

```cmd
npm install
npx expo install --fix
npx expo start -c
```

4. На iPhone відкрий Expo Go (SDK 58), відскануй новий QR-код. ПК та iPhone мають бути в одній Wi-Fi мережі.

Якщо інсталяція поводиться дивно після зміни SDK: закрий Expo, видали локальні папки `node_modules`, `.expo` та старий `package-lock.json` тільки **в mobile**, після чого повтори команди. Це не впливає на сайт або базу даних.

## Що є у версії 0.2.0

- Вхід, реєстрація, відновлення пароля (через сайт) і спільний акаунт з KONTA.
- Стрічка, публікація дописів з фото, лайки, коментарі, редагування та видалення своїх коментарів.
- Пошук людей за ім'ям та @ніком, заявки у друзі, прийняття заявок.
- Власний профіль, редагування імені, ніку, опису й аватара.
- Особисті чати, надсилання, редагування й видалення власних повідомлень (якщо доступ дозволяє база).
- Список сповіщень, спільноти, фото, ігри. «Бутилочка» та каталог ігор відкриваються у вбудованій веб-сторінці; для веб-гри може знадобитися окремий вхід.
- Автооновлення даних приблизно кожні 30 секунд, ручне оновлення.

## Відомі обмеження

Це **тестова** версія, не повністю перевірений реліз App Store. Підготовка до публікації потребує окремої роботи: модерація контенту та скарги/блокування, видалення акаунта, політика приватності, іконка, скриншоти, push-сповіщення й перевірка Apple. Історії поки додаються, але повноцінний переглядач потребує додаткового тестування. Фото обмежені типовими форматами бібліотеки iPhone; інші медіа (музика/відео) із сайту не перенесені як нативне редагування.

## Приватність

Публічний Supabase publishable key використовується лише для клієнта; доступ до користувацьких даних регулюється політиками RLS у наявній базі KONTA. Service-role ключ ніколи не зберігай у застосунку.
