# KONTA для iPhone — початкова версія

Перший нативний застосунок на Expo: вхід, реєстрація і збереження сесії Supabase. Це **не** готовий до App Store застосунок: нативні стрічка, чати, профілі, модерація та видалення акаунта ще потребують реалізації.

## Запуск із Windows

1. Встанови Node.js LTS.
2. Відкрий термінал у папці `mobile` і виконай `npm install`, потім `npx expo start`.
3. Встанови **Expo Go** на iPhone, підключи телефон і ПК до однієї Wi-Fi мережі та відскануй QR-код камерою iPhone.
4. Якщо локальна мережа не працює, спробуй `npx expo start --tunnel` (може знадобитися `@expo/ngrok`).

## Далі
